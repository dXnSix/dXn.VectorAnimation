The [Rive community](https://rive.app/community/files/28444-53782-snake-raster-animation/)'s `snake-raster-animation`, read by `dxn_vector_animation_rive` in the
browser and played by the NSH player as it is: its artboard's default state machine runs, a pointer over it
reaches its listeners, and its view model is bound.

## What it exercises

- 574 raster images
- 87,631 keyframes over a one-second loop

The file is [`examples/gallery/animations-rive/28444-53782-snake-raster-animation.riv`](https://github.com/dXnSix/dXn.VectorAnimation/blob/main/examples/gallery/animations-rive/28444-53782-snake-raster-animation.riv);
`vector-animation inspect` lists its inputs, listeners and what it leaves out. What the importer reads is in
[Rive](../rive.md).
